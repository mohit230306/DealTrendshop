📘 Setup guide: Google Sheet + Apps Script

1. Create the Google Sheet. Open sheets.google.com → Blank → name it e.g. “Orders Database”.

2. Column headers. The script creates them automatically on the first order. Tab Orders: Order ID · Date and Time · Customer Name · Mobile Number · Full Address · City · State · PIN Code · Product Name · Product Code · Product Price · Quantity · Total Amount · Order Status. Tab Products: Product Code · Product Name · Price · Description · Image URL · Stock Status.

3. Open Apps Script. In the Sheet: Extensions → Apps Script.

4. Paste Code.gs. Delete everything in the editor, tap “Copy Code.gs” below, paste, and change ADMIN_KEY to your own secret. Save.

View Code.gs

        
5. Deploy as Web App. Deploy → New deployment → gear icon → Web app. Execute as: Me. Who has access: Anyone. Tap Deploy and approve the permissions (Advanced → Go to project).

        
6. Copy the Web App URL (ends with /exec).

        
7. Paste it into this file. Find GOOGLE_SCRIPT_URL near the top of the script and replace the placeholder. To try it first, paste it into Connection settings above and tap Test connection.

        
8. After editing Code.gs later use Deploy → Manage deployments → ✏️ → Version: New version → Deploy, otherwise the old code keeps running.

        
Images: upload a picture to Google Drive, share it as “Anyone with the link”, and paste the share link in the product form — it is converted to a direct image URL automatically.

        
Important: add/edit products here, then they sync to the Products tab so every customer sees them. Pictures uploaded straight from your phone stay on this device only — use a Drive/image URL for those.
